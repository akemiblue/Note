# 4. 練習のしかた ― TradingViewは「練習場」として使え

チャートの見方を覚えても、それだけでは勝てません。
**練習量がすべてです。** サッカーのルールを覚えただけの人が試合で勝てないのと同じ。

TradingViewには、**お金を1円も使わずに練習できる機能**が3つあります。
これを使い倒してください。

---

## 4-1. バーリプレイ ― 過去に巻き戻して勝負する【最強の練習】

### これは何？

チャートを**過去のある日まで巻き戻して、そこから1本ずつ進める**機能です。
未来が隠されるので、**当時のリアルな判断を追体験できます。**

> ゲームでいうと「セーブデータをロードして、その場面をやり直す」機能。
> **本番と同じ状況を、何百回でも繰り返せる**のが最強なところです。

### やり方

1. 上のバーの **⏱（バーリプレイ）** をクリック
2. チャート上で**巻き戻したい日**をクリック → そこから先が隠れる
3. **▶（次のバー）** を押すと1本ずつ進む
4. 再生ボタンで自動再生（速度調整可）

> 無料プランでは日足など長めの足で使えます。分足のリプレイは有料プランです。
> **初心者は日足でやるべきなので、無料で十分。**

### 正しい練習のやり方（これが超重要）

ただ眺めるのは練習ではありません。**必ず紙かメモに書いてください。**

**1回のリプレイでやること：**

```
① ランダムな過去の日まで巻き戻す
② 今のチャートだけを見て、以下を紙に書く
   ・トレンドは？（上／下／レンジ）
   ・買う？ 売る？ 見送る？
   ・買うなら：いくらで買う？ いくらで損切り？ いくらで利確？
   ・その理由（1〜2行）
③ 1本ずつ進めて、結果を見る
④ 結果を書く：勝ち／負け／いくら動いたか
⑤ 「なぜそうなったか」を1行で書く
```

**目標：50〜100回。**
これをやると、「なんとなく上がりそう」が
「25日線で下ヒゲ＋出来高増だから買い」に変わります。

### ⚠️ リプレイの落とし穴

- **チャートを右にスクロールして未来を見ない**（絶対）
- **「あの株は結局上がった」という記憶がある銘柄は避ける**
  → 知らない銘柄・知らない年でやること
- **勝った理由も必ず書く**。まぐれで勝った回を「実力」と思うのが一番危険

## 4-2. ペーパートレード ― 架空のお金で本番と同じ売買

### これは何？

**架空の資金**で、実際の相場に対して売買の練習ができる機能です。
リプレイが「過去の再現」なら、こちらは「**今、リアルタイムでの本番練習**」。

### やり方

1. チャート下部のパネルから「**取引パネル**」を開く
2. ブローカー（証券会社）の選択で「**Paper Trading**（ペーパートレード）」を選ぶ
3. 接続すると架空の資金が入る
4. あとは本物と同じように買い・売りの注文を出す

### 練習のポイント

- **架空資金を「30万円」に設定する**（設定でリセット・金額変更ができます）
  → 本番と同じ金額でやらないと、練習になりません。
  100万円の架空資金でやると、金銭感覚が本番とズレます
- **必ず損切り注文（ストップ）も一緒に入れる**
- **最低3ヶ月続ける。** 1ヶ月だと「たまたま良い相場だった」がわからない
- **記録をつける**（次のセクション）

### 卒業の条件（自分で決めておく）

以下を全部クリアするまで、本物のお金を使わない：

- [ ] ペーパートレードを **3ヶ月以上** 継続した
- [ ] **30回以上** の売買を記録した
- [ ] **すべての売買で損切りラインを決めていた**
- [ ] トータルで **プラス**になっている
- [ ] 「ルールを破った回」が **1回もない**（勝敗より、これが重要）

## 4-3. アラート ― 画面に張り付かない技術

### これは何？

「この値段になったら教えて」を設定しておく機能です。
スマホアプリに通知が飛びます。

### なぜ大事か

**チャートを一日中見ていると、必ず負けます。**

理由：見ていると「何かしたくなる」から。
これを **ポジポジ病** といい、初心者が資金を溶かす最大の原因です。

アラートを使えば、**「その値段が来るまで、チャートを閉じていられる」**。
これは技術というより **メンタル管理の道具** です。

### 設定のしかた

1. チャート上で右クリック → 「**アラートを追加**」
   （または上のバーの 🔔）
2. 条件を決める：
   - `価格が 3,500 を上抜けたら`
   - `25日移動平均線を下抜けたら`（引いた線やインジケーターにも設定できます）
3. 通知方法：アプリのプッシュ通知 / メール
4. 保存

### おすすめの使い方

- 引いた**支持線・抵抗線にアラートを置く**
- 「ここまで下がったら押し目買いを検討」の値段に置く
- **1日1回、決まった時間にだけチャートを見る**（例：夜21時に15分だけ）
  → あとはアラート任せ

## 4-4. ウォッチリストとスクリーナー ― 探す作業を仕組みにする

### ウォッチリスト
右のサイドバーに、気になる銘柄を登録するリスト。

**作り方のコツ：**
- **5〜15銘柄まで。** 多いと絶対に見なくなります
- 「自分が知っている会社」から始める（ゲーム・食品・鉄道など）
- リストを分ける：`監視中` / `買い候補` / `保有中`

### ストックスクリーナー
条件を指定して銘柄を絞り込む機械。下のパネルから開けます。

**初心者向けの条件例（日本株）：**
```
・時価総額：500億円以上          （小さすぎる会社は値動きが乱暴）
・1日の出来高：50万株以上        （売りたいときに売れないと困る）
・株価：値段が200日移動平均より上  （下降トレンドを最初から除外）
```

これで出てきた銘柄を、日足チャートで1つずつ見る。
**「探す」を仕組み化すると、続けられます。**

## 4-5. 【最重要】売買記録ノートをつける

**これをやる人は、ほぼ確実に上達します。やらない人は、5年経っても同じ失敗を繰り返します。**

上手くなるとは「同じ失敗をしなくなる」ことです。
記録がないと、自分が何を間違えたのか永久にわかりません。

### 記録する項目

| 項目 | 例 |
|---|---|
| 日付 | 2026-09-03 |
| 銘柄 | TSE:7203 |
| 買/売 | 買い |
| 入った値段 | 2,850 |
| **損切り値段** | 2,760 |
| **利確目標** | 3,030 |
| **リスク:リワード** | 90円損 : 180円益 = **1:2** |
| 買った理由 | 上昇トレンド中、25日線で下ヒゲ＋出来高増 |
| 結果 | +180円 / -90円 |
| **ルールを守れたか** | ○ / ×（← ここが一番大事） |
| 気づいたこと | 焦って1日早く入った。次は確定を待つ |

### 月に1回、必ず振り返る

- 勝率は？（**60%なくてもOK**。リスクリワードが1:2なら勝率40%でも増えます）
- **ルール違反した回はどれくらい？** → ここを減らすのが上達
- 負けた回に共通点はある？（時間帯／銘柄／トレンドに逆らった／損切りをずらした）

> 💡 **勝った負けたより「ルールを守れたか」を評価してください。**
> ルールを破って勝った回は、**将来の大損の練習**をしているのと同じです。

## 4-6. スマホアプリ

TradingViewにはスマホアプリもあります（iOS / Android）。

**使い分けの正解：**
- **スマホ＝アラートを受け取る・値段をチラ見するだけ**
- **PC＝分析する・注文を決める**

**スマホで衝動的に売買しないこと。** 画面が小さく、感情で押しやすいので、
初心者が最も損をしやすい環境です。

## この章のまとめ ― 90日の練習メニュー

| 期間 | やること |
|---|---|
| **1〜2週目** | 画面に慣れる。日足で10銘柄を毎日眺める。線を引く練習 |
| **3〜4週目** | インジケーター3つを設定。トレンド判定を毎日ノートに書く |
| **2ヶ月目** | **バーリプレイ50回。** 全部ノートに記録 |
| **3ヶ月目** | **ペーパートレード開始。** 架空資金30万円。ルールを文章化する |
| **4ヶ月目〜** | ペーパートレードを3ヶ月継続。卒業条件をクリアしたら、**少額**で実弾へ |

**この6ヶ月を飛ばして本番に行った人は、ほぼ全員が資金を減らします。**
逆に、この6ヶ月をやり切った人は、上位10%です。
