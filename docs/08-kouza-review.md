### 最重要ページ：上がらない時期

| 期間 | 長さ | 内容 |
|---|---|---|
| 1929年〜1953年 | **24年間** | 世界恐慌。高値回復まで |
| 1965年〜1981年 | **16年間** | 金利上昇期。ほぼ横ばい |
| 1981年〜2022年 | 41年間 | 金利低下期。40年上昇 |

**ほとんどの投資教材は「米国株は上がり続ける」としか言いません。**
この講座は「上がらない時期が15〜25年ある」と教えています。**高く評価すべき点です。**

### これは、このノートの計画への正当な批判材料でもある

最初の10年が横ばいだった場合（月2万円積立・現金30万円込み）：

| 最初の10年 | その後10年 | 20年後 |
|---|---|---|
| 年+8% | 年+8% | **1,352万円**（基本想定） |
| **年 0%** | 年+8% | **992万円** |
| 年−2% | 年+10% | 1,092万円 |
| 年+8% | **年 0%** | **701万円** |

**この幅が現実に起きうる範囲です。**

### そして講座Bの警告は、計画の3本柱を全部補強する

| 講座Bの警告 | 必要な対策 | 計画に入っているか |
|---|---|---|
| 米国が15〜25年上がらないことがある | **分散**（米国だけに賭けない） | ✅ 全世界株1本へ |
| 相場に頼れない時期がある | **入金力**（相場と無関係な力） | ✅ 月2万円→増やす |
| 横ばい10年を耐える必要がある | **生活防衛資金**（売らずに済む力） | ✅ 現金30万円 |

**横ばい相場は、積立にとっては「安く仕込める期間」です。**
価格が半分の期間、同じ2万円で2倍の口数が買えます。

> ただし条件が1つ。**その10年間、売らずに積立を続けられること。**
> そのために必要なのが、生活防衛資金です。

## ★上書きが必要な2つ★

### ① リスク量（講座4章 ATRの例題）

講座の例：資金50万円／川崎汽船9107（株価2400円・ATR約130円）

| 項目 | 講座の例 | 資金比 |
|---|---|---|
| ポジション | 480,000円 | **資金の96%を1銘柄に** |
| 1回の損切り | 50,000円 | **資金の10%** |
| 目標月利 | 100,000円 | **資金の20%／月** |

**このノートのルールは「1回の損失は総資産の2%まで」。講座の例はその5倍です。**

> 講座は「1回の大損は厳禁」「負けない投資が大前提」と正しいことを教えています。
> **でも例題自身が、その教えを守っていません。**

**4連敗したときの差：**

| | 1回10%（講座の例） | 1回2%（このノート） |
|---|---|---|
| 4連敗後 | 資金 −40% | 資金 −7.8% |
| 10連敗後 | ほぼ壊滅 | **資金の82%が残る** |

### ② 目標月利（＝「億資産」の根拠）

月利20%を複利で回すと：

| | |
|---|---|
| 12ヶ月後 | 446万円 |
| 24ヶ月後 | 3,975万円 |
| **29ヶ月後** | **約1億円** |
| **年換算** | **年792%** |

数学的には正しい計算です。ただし**年792%**。
このノート序章で検証したとおり、**年75.5%ですら歴史上誰も達成していません。** その10倍です。

**「目標月利を決める」という発想そのものを採用しないでください。**
相場から毎月同じ給料は取れません。この発想が、無理なトレードを誘発します。

## 講座の数学への補足：4連敗の確率

講座の説明：
> 勝率6割＝4割負け。0.4⁴ = 2.56%。「100人中2〜3人は4連敗する」

これは**「ある特定の4回が全部負ける確率」**です。
実際に問題になるのは**「何十回もトレードする途中で、1度でも4連敗が起きる確率」**です。

| トレード回数 | 4連敗を経験する確率 |
|---|---|
| 10回 | 11.7% |
| 30回 | 36.6% |
| **50回** | **54.4%** |
| **100回** | **80.1%** |

**100回やれば10人中8人が4連敗を経験します。** 「2〜3人」ではありません。
だからこそ、1回の損失を2%に抑える必要があります。

## いつ使うか

**知識として学ぶのは今すぐ。実弾で使うのは、生活防衛資金30万円ができてから。**

理由は1つ。講座が想定している受講者は
**「資金50万〜300万円があり、生活防衛資金もある人」**です。

講座自身が、いちばん良い問いを立てています。

> **「その銘柄は自分のための銘柄なのか」**

この問いを自分に向けてください。今の答えは **「まだ違う」**。
盾ができたら、答えは変わります。
