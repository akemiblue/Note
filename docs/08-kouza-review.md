**詐欺ではありません。内容の大部分はまっとうで、このノートと重なる部分が多いです。**

## ★上書きが必要な2つ★

### ① リスク量（講座4章 ATRの例題）

講座の例：資金50万円／川崎汽船9107（株価2400円・ATR約130円）

| 項目 | 講座の例 | 資金比 |
|---|---|---|
| ポジション | 480,000円 | **資金の96%を1銘柄に** |
| 1回の損切り | 50,000円 | **資金の10%** |
| 目標月利 | 100,000円 | **資金の20%／月** |

**このノートのルールは「1回の損失は総資産の2%まで」。講座の例はその5倍です。**

> 講座は「1回の大損は厳禁」「負けない投資が大前提」と正しいことを教えています。
> **でも例題自身が、その教えを守っていません。**

**4連敗したときの差：**

| | 1回10%（講座の例） | 1回2%（このノート） |
|---|---|---|
| 4連敗後 | 資金 −40% | 資金 −7.8% |
| 10連敗後 | ほぼ壊滅 | **資金の82%が残る** |

### ② 目標月利（＝「億資産」の根拠）

月利20%を複利で回すと：

| | |
|---|---|
| 12ヶ月後 | 446万円 |
| 24ヶ月後 | 3,975万円 |
| **29ヶ月後** | **約1億円** |
| **年換算** | **年792%** |

数学的には正しい計算です。ただし**年792%**。
このノート序章で検証したとおり、**年75.5%ですら歴史上誰も達成していません。** その10倍です。

**「目標月利を決める」という発想そのものを採用しないでください。**
相場から毎月同じ給料は取れません。この発想が、無理なトレードを誘発します。

## 講座の数学への補足：4連敗の確率

講座の説明：
> 勝率6割＝4割負け。0.4⁴ = 2.56%。「100人中2〜3人は4連敗する」

これは**「ある特定の4回が全部負ける確率」**です。
実際に問題になるのは**「何十回もトレードする途中で、1度でも4連敗が起きる確率」**です。

| トレード回数 | 4連敗を経験する確率 |
|---|---|
| 10回 | 11.7% |
| 30回 | 36.6% |
| **50回** | **54.4%** |
| **100回** | **80.1%** |

**100回やれば10人中8人が4連敗を経験します。** 「2〜3人」ではありません。
だからこそ、1回の損失を2%に抑える必要があります。

## 触ってはいけない3つ（講座C）

| 内容 | 判定 |
|---|---|

| **空売り** | ❌ **損失に上限がない**（株は0円までだが、上には無限） |

## 変換表（講座を受けながら、手元に置く）

| 講座の教え | 判定 | 自分のルール |
|---|---|---|
| 大数の法則・確率のゲーム | ✅ そのまま | — |
| 負けない投資・1回の大損は厳禁 | ✅ そのまま | — |
| 損切りライン・逆指値 | ✅ そのまま | 買った直後に必ず入れる |
| ATRで損切り幅を測る | ✅ 採用 | 使ってよい |
| ローソク足・チャートパターン | ✅ 採用 | 第2章と同じ |
| 1日1回チェック・21日習慣化 | ✅ 採用 | — |
| 連敗の想定 | ⚠️ 強化 | **4連敗ではなく10連敗を想定** |
| **1回の損失＝資金の10%** | ❌ **上書き** | **総資産の2%** |
| **ポジション＝資金の96%** | ❌ **上書き** | **1銘柄は総資産の10%まで** |
| **目標月利を決める** | ❌ **廃止** | 相場から給料は取れない |
| FXデイトレード／空売り／CFD | ❌ **禁止** | 最初の2年 |

**例：講座に「川崎汽船を200株（48万円）」と出てきたら、自分は47株（単元未満株）。**
これが正しい変換です。

## いつ使うか

**知識として学ぶのは今すぐ。実弾で使うのは、生活防衛資金30万円ができてから。**

理由は1つ。講座が想定している受講者は
**「資金50万〜300万円があり、生活防衛資金もある人」**です。

講座自身が、いちばん良い問いを立てています。

> **「その銘柄は自分のための銘柄なのか」**

この問いを自分に向けてください。今の答えは **「まだ違う」**。
盾ができたら、答えは変わります。
