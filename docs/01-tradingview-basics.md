# 1. TradingViewとは何か／画面の見方

日本語版： https://jp.tradingview.com/

---

## 1-1. TradingViewって何？

ひとことで言うと **「株や為替や仮想通貨の値段のグラフを見るための、世界一使われている道具」** です。

学校の理科でグラフ用紙に折れ線を書きましたよね。あれの超高性能版です。

- 値段の動きを**グラフ（チャート）**で見られる
- グラフの上に**線を引いたりメモを書いたり**できる
- 「平均の線」みたいな**補助の道具（インジケーター）**を重ねられる
- 「この値段になったら教えて」という**アラート**を鳴らせる
- **過去に巻き戻して**、練習ができる

大事なこと：
**TradingViewは「見る・練習する」ための道具です。ここで直接、株を買うのがメインではありません。**
実際にお金を出して買うのは、証券会社（SBI証券、楽天証券など）のアプリです。

> たとえるなら
> **TradingView＝作戦を立てる部室のホワイトボード**
> **証券会社のアプリ＝実際に試合に出るグラウンド**

---

## 1-2. 登録する（無料でOK）

1. https://jp.tradingview.com/ を開く
2. 右上の「**始める**」または「**サインイン**」から無料アカウントを作る（メール or Google等）
3. 上のメニューの「**チャート**」を押す → これがメイン画面

**最初は無料プラン（Basic／ベーシック）で十分です。** お金を払うのは、
「無料の制限が本当に邪魔だ」と自分で感じてからで遅くありません。

### 無料プランでできること・できないこと（ざっくり）

| | 無料 | 有料 |
|---|---|---|
| チャートを見る | ○ | ○ |
| 線を引く・メモする | ○ | ○ |
| 1つのチャートに乗せる補助の道具 | **少数まで（2個程度）** | 5個〜25個 |
| 画面を分割して複数チャート | ×（1つ） | 2〜8分割 |
| アラート（値段の通知） | **少数まで** | 大量 |
| 広告 | 出る | 消える |
| 日本株のリアルタイム価格 | **20分遅れ** | 別途データ契約で即時 |
| 過去に巻き戻す練習（リプレイ） | 日足など○／分足は× | ○ |

> ⚠️ **プランの名前・料金・上限は頻繁に変わります。**
> 必ず https://jp.tradingview.com/pricing/ で最新を確認してください。
> このノートの数字は「だいたいこんな感じ」という目安です。

**「20分遅れ」の意味**：無料だと日本株の値段が20分前のものです。
勉強と練習には**まったく問題ありません**（むしろ「今すぐ飛びつく」クセがつかなくて良い）。
デイトレード（1日で何回も売買）をするなら困りますが、初心者はやらない方がいいので、やはり問題ありません。

## 1-3. 画面の見方 ― どこに何があるか

チャート画面は、大きく **5つのブロック** に分かれています。

```
┌─────────────────────────────────────────────────┐
│ ① 上のバー（銘柄・時間・チャート型・インジケーター）      │
├───┬─────────────────────────────────┬───────┤
│ ② │                                             │  ④    │
│ 左 │          ③ チャート本体                       │  右   │
│ の │      （ローソク足が並ぶメインの場所）           │  サイド│
│ 道 │                                             │  バー  │
│ 具 │                                             │       │
├───┴─────────────────────────────────┴───────┤
│ ⑤ 下のパネル（ストックスクリーナー／ペーパートレード等）    │
└─────────────────────────────────────────────────┘
```

### ① 上のバー（ツールバー）― 一番よく使う

左から順に：

| ボタン | 名前 | 何をするもの |
|---|---|---|
| 🔍 銘柄名 | **シンボル検索** | 「トヨタ」「7203」「USDJPY」など、見たいものを選ぶ |
| 1D / 5m など | **時間足（じかんあし）** | ローソク1本を何分・何日にするか |
| ローソクの絵 | **チャートタイプ** | ローソク足／ライン／平均足などの表示切替 |
| ⚡ | **インジケーター** | 移動平均線などの補助道具を追加 |
| ⏱ | **バーリプレイ** | 過去に巻き戻して練習する |
| ↺ ↻ | 元に戻す／やり直し | 間違えたらここ（Ctrl+Z） |
| 💾 | 保存 | チャートのレイアウトを保存 |
| ⚙️ | 設定 | 色・目盛りなどの見た目を変える |
| 🔔 | アラート | 「この値段になったら通知して」 |

**シンボルの探し方（日本株の例）**
検索ボックスに `7203`（トヨタ）と打つと候補が出ます。
`TSE:7203` のように「取引所:コード」で表示されます。TSE＝東京証券取引所。

よく使うシンボル例：
- 日経平均 → `NI225`
- 米国のS&P500 → `SPX` / ETFなら `SPY`
- ドル円 → `USDJPY`
- ビットコイン → `BTCUSD`

### ② 左の道具箱（描画ツール）

チャートに線や図形を書き込むための道具が縦に並んでいます。
最初に覚えるのは **たった3つ**でOK。

| 道具 | ショートカット | 使いどころ |
|---|---|---|
| **トレンドライン**（斜めの線） | `Alt + T` | 上がり調子・下がり調子の「道すじ」を引く |
| **水平線** | `Alt + H` | 「この値段でよく止まる」ラインを引く |
| **長方形** | ― | 「この値段の帯で止まる」ゾーンを塗る |

他にも「フィボナッチ」「文字メモ」「絵文字」などがありますが、**最初は無視**していいです。
道具が多いほど上手くなるわけではありません。

💡 **ゴミ箱アイコン**：引いた線を全部消したいときに使います。

### ③ チャート本体

ローソク足が並ぶメインの場所。

- **右の数字の列＝価格軸**（値段）
- **下の日付の列＝時間軸**
- マウスのホイールで**拡大・縮小**
- ドラッグで**左右に移動**
- 右下の「**⤢**」みたいなボタンで **全体表示に戻る**（迷子になったらこれ）

チャートの下に、細い棒グラフが出ていることがあります。それが**出来高（できだか）**。
「その日、どれくらいの量が売り買いされたか」です。後で説明します。

### ④ 右のサイドバー

- **ウォッチリスト**：気になる銘柄をお気に入り登録する場所。**毎日ここを見るのが習慣づくり**
- **アラート**：設定した通知の一覧
- **ニュース**：その銘柄のニュース
- **チャット**：他のユーザーの雑談。**初心者は見ないほうがいい**（人の意見に流される原因No.1）

### ⑤ 下のパネル

- **ストックスクリーナー**：条件を決めて銘柄を絞り込む機械（「PERが15倍以下の日本株」など）
- **ペーパートレード**：**架空のお金で売買を練習できる機能**。最重要。詳しくは第4章
- **Pineエディタ**：自分で売買ルールをプログラムする場所（上級。今は無視）

---

## 1-4. 最初にやる設定（5分）

1. **時間足を「1D（日足）」にする** ← 初心者は日足から。分足は情報が多すぎて混乱します
2. **チャートタイプを「ローソク足」にする**
3. 設定（⚙️）→ シンボル → **ローソクの色**を確認（日本式は陽線が赤、世界標準は陽線が緑。どちらでもいいので自分が混乱しない方に）
4. **ウォッチリストに5〜10銘柄だけ**登録する（多すぎると見なくなります）
5. 保存（💾）してレイアウトに名前をつける

---

## 1-5. 覚えると速いショートカット

| キー | 動作 |
|---|---|
| `Ctrl + Z` | 元に戻す |
| `Alt + T` | トレンドライン |
| `Alt + H` | 水平線 |
| `Alt + I` | チャートの色を反転 |
| `,` `.` | 時間足を切り替え（数字キーでも） |
| `↑` `↓` | 縦の拡大・縮小 |

## この章のまとめ

- TradingViewは**見る・練習する道具**。買うのは証券会社のアプリ
- 無料プランで十分に勉強できる
- 覚える場所は **上のバー・左の道具箱・右のウォッチリスト** の3つだけ
- 最初は **日足 × ローソク足 × 線は2種類だけ**
