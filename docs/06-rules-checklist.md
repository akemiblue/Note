# 6. 自分の売買ルールを作る ＋ 毎回使うチェックリスト

---

## 6-1. なぜ「ルール」が必要なのか

チャートを読めるようになっても、**その場の気分で売買したら意味がありません。**

人間の脳は、投資に向いていません。
- 上がってると「乗り遅れる！」と焦る（**FOMO**）
- 下がると「もう終わりだ」と怖くなり、底で売る
- 損を認めたくないので、損切りをずらす
- 勝つと自分が天才だと思い、次でサイズを上げて全部返す

**ルールとは、「冷静なときの自分」が「興奮している自分」に出す命令書**です。

---

## 6-2. ルールのテンプレート（自分用に埋める）

コピーして、自分の言葉で埋めてください。**紙に書いて机に貼る**のがおすすめです。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  私の売買ルール（          年   月   日 版）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【0】使う資金
  ・箱2（個別株）に使う金額：            円
  ・1回の売買で失っていい額（2%）：      円

【1】何を取引する？
  ・対象：（例）日本株の単元未満株 ／ 米国株
  ・時間足：（例）日足で判断、週足で流れを確認
  ・銘柄の条件：（例）時価総額500億以上、出来高50万株以上

【2】買う条件（★全部○のときだけ買う★）
  □ 週足の流れが上向き
  □ 日足で株価が200日移動平均線の上
  □ 25日移動平均線 or 支持線まで押してきた
  □ そこで下ヒゲ or 陽線が出た（買いの手が入った証拠）
  □ 出来高が伴っている
  □ 損切りラインを決められる場所にいる
  □ リスク:リワードが 1:2 以上ある

【3】どこで損切りする？
  ・（例）直近の安値の少し下 ／ 25日線を終値で割ったら
  ・買った直後に、必ず逆指値注文を入れる

【4】どこで利確する？
  ・目標1：リスクの2倍の値幅に到達したら → 半分売る
  ・目標2：残りは25日線を割るまで持つ（トレイリング）

【5】やらないこと
  ・信用取引／レバレッジ　　→ 最初の2年は禁止
  ・決算発表をまたいで持つ　→ （初心者は避ける。値が飛ぶため）
  ・負けを取り返すための追加売買（リベンジトレード）
  ・SNSや動画で見た銘柄を、自分で確認せずに買う
  ・同時に持つ銘柄は        個まで

【6】メンタルのルール
  ・チャートを見るのは1日        回、        分だけ
  ・2連敗したら、その日は終了
  ・月に−6%（3回分）まで負けたら、その月は取引停止して見直す

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 6-3. 買う前チェックリスト（毎回、必ず使う）

**スクショしてスマホに入れるか、印刷して机に置いてください。**

```
【買う前・30秒チェック】

 ■ 環境
 □ 週足の流れは上向きか？               → ×なら 見送り
 □ 日足で200日線の上にいるか？           → ×なら 見送り

 ■ 場所
 □ 買う理由を1行で言えるか？
     「_______________________ だから買う」
 □ 高値に飛びついていないか？（追いかけ買いは禁止）

 ■ お金
 □ 損切りの値段はいくら？        ______ 円
 □ 1株あたりの損失額は？          ______ 円
 □ 買う株数 =（資金×2%）÷ 1株の損失 = ______ 株
 □ 利確目標はいくら？            ______ 円
 □ リスク:リワードは 1:2 以上か？        → ×なら 見送り

 ■ 心
 □ 焦っていないか？（「今すぐ買わないと」は危険信号）
 □ 損を取り返そうとしていないか？
 □ 全部失っても生活に困らない金額か？

 → 1つでも「×」があれば → 【買わない】
```

**「買わない」は最強の一手です。**
機会は毎日あります。資金は一度失うと戻りません。

## 6-4. 売った後チェックリスト

```
【売ったあと・記録】

 □ 日付・銘柄・買値・売値・株数
 □ 結果：+____円 ／ −____円
 □ ルールを守れたか：  ○ ／ ×
      × なら、どのルールを破った？ ________________
 □ 良かった判断： ________________
 □ 次に直すこと（1つだけ）： ________________
```

> 💡 **「次に直すこと」は毎回1つだけ**にしてください。
> 10個直そうとすると、0個も直りません。

## 6-5. 月末レビュー（月1回・30分）

```
【今月の成績】
 ・売買回数：      回
 ・勝ち：   回 ／ 負け：   回 ／ 勝率：    %
 ・合計損益：        円
 ・ルール違反：      回   ← ★これが最重要指標★

【分析】
 ・一番大きい負けの原因は？
 ・ルール違反した回は、全部でいくら損した／得した？
 ・勝った回に共通点はある？
 ・負けた回に共通点はある？（時間帯／銘柄の種類／相場全体の状況）

【来月の1つの改善点】
 → ________________________________
```

**評価の順番はこれです：**

1. **ルールを守れたか**（最重要）
2. リスク管理ができていたか
3. 損益（最後）

**ルール違反ゼロで負けた月は、良い月です。**
**ルール違反して勝った月は、悪い月です。**（将来の大損の予行演習をしています）

## 6-6. 上達の段階 ― 今どこにいるか

| 段階 | 状態 | やること |
|---|---|---|
| **Lv.0 無知** | 何を知らないかも知らない | この章までを読む |
| **Lv.1 知識** | 用語はわかるが判断できない | 毎日チャートを見る。線を引く |
| **Lv.2 分析** | 判断はできるが、その通りに動けない | **リプレイ100回**。ペーパートレード |
| **Lv.3 規律** | ルール通りに動ける | 少額の実弾。記録を続ける |
| **Lv.4 一貫性** | 数ヶ月単位でプラスを維持できる | サイズを少しずつ上げる |

**ほとんどの人は Lv.2 で実弾に行って退場します。**
**Lv.3（ルール通りに動ける）に達してから、お金を入れてください。**

## 6-7. よくある質問

**Q. 何時間くらい勉強すればいい？**
A. 毎日30分を6ヶ月。これが一番効率的です。週末に8時間まとめてやるより、毎日30分が勝ちます。

**Q. インジケーターは何を使うのが正解？**
A. 正解はありません。「みんなが見ているもの（移動平均・出来高・RSI）」を、
「自分が理由を説明できる形で」使うのが正解です。

**Q. 有料プランは必要？**
A. 最低6ヶ月は無料で。「無料の制限が本当に邪魔だ」と自分の言葉で説明できるようになってからで十分です。

**Q. デイトレードはやるべき？**
A. 初心者は**やらないでください**。取引回数が多いほど、手数料と感情のミスが積み上がります。
日足でゆっくり判断する方が、圧倒的に勝ちやすいです。

**Q. AIやシグナル配信を使えば勝てる？**
A. 有料シグナル配信のほとんどは、配信者が儲かる仕組みです。
本当に勝てる方法を持っている人は、それを月額数千円で売りません。

**Q. 5年で1000万に届かなかったら失敗？**
A. いいえ。**続けていれば、6年目・7年目で届きます。**
複利は後半のほうが強いので、途中でやめることだけが本当の失敗です。

## 最後に ― このノートで一番大事な1文

> **「早く増やそうとすると、必ず失う。
>   ゆっくり増やそうとすると、意外と早く増える。」**

30万円を守りながら、入金を続け、腕を磨いてください。
5年後にあなたが持っているべき本当の資産は、
500万円という数字よりも、**「一貫してルール通りに動ける自分」**です。

その自分がいれば、そこから先の1000万も、2000万も、時間の問題になります。
