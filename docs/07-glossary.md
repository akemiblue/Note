# 7. 用語辞典 ― 全部、中学生の言葉で

投資の本が読めないのは、頭が悪いからではなく **言葉を知らないだけ** です。
ここを1回通れば、たいていの本と動画が読めるようになります。

**読み方：** 最初から順に読む必要はありません。わからない言葉が出たら、ここに戻ってきてください。

---

## A. お金の増え方

### 複利（ふくり）
**利益が、次の利益を生むこと。** 雪だるまを転がすと、大きくなるほど雪がつくスピードも上がる。あれです。

- **単利**：元の30万円にだけ利息がつく
- **複利**：増えた分にも利息がつく

30万円を年10%で回した場合：

| | 単利 | 複利 | 差 |
|---|---|---|---|
| 5年後 | 45万 | 48万 | 3万 |
| 10年後 | 60万 | 78万 | 18万 |
| 20年後 | 90万 | 202万 | 112万 |
| **30年後** | **120万** | **523万** | **403万** |

最初の5年はほとんど差がないのに、30年で4倍以上の差になります。
**複利は後半で爆発する。** だから「早く始めて、途中でやめない」が最強なのです。

### 72の法則
**72 ÷ 年利（%）＝ お金が2倍になる年数。** 暗算用の便利ワザです。

| 年利 | 2倍になるまで |
|---|---|
| 年3% | 24年 |
| 年5% | 14.4年 |
| **年8%** | **9年** |
| 年10% | 7.2年 |
| 年20% | 3.6年 |

### 利回り（りまわり）
**1年でお金が何%増えたか。** 30万円が33万円になったら利回り10%。

### 元本（がんぽん）
**自分が出したお金そのもの。** 利益を含まない、投入した現金のこと。
「元本割れ」＝ 出したお金より減ってしまうこと。

### インフレ
**モノの値段が上がり、お金の価値が下がること。**
100円だったジュースが120円になったら、あなたの100円玉は**ジュース1本も買えなくなった**＝価値が下がった。

年2%のインフレが続くと、現金は毎年2%ずつ価値が減ります。
**「投資しない＝安全」ではありません。** 現金で持っていることも、それ自体がひとつの賭けです。

## B. 何を買うのか

### 株式（かぶしき）
**会社のオーナー権を、小さく切り分けたもの。** 1株買えば、あなたはその会社のほんの一部の持ち主です。
会社が儲かれば株価が上がり、配当（利益のおすそわけ）がもらえることもあります。

### インデックス（指数）
**市場全体の平均点。**

| 名前 | 中身 |
|---|---|
| 日経平均株価 | 日本の代表225社の平均 |
| TOPIX | 東証の広い範囲の平均 |
| S&P500 | 米国の代表500社の平均 |
| 全世界株インデックス | 世界中の約3,000社の平均 |

### インデックス投資
**その平均点を、そのまま買うこと。**
「どの会社が伸びるか」を当てにいかず、**全部を少しずつ買って市場全体の成長をもらう**やり方。

> クラスで一番になる生徒を当てるのは難しい。でも**クラスの平均点**なら、そこそこ安定して読めます。それを買うイメージ。

強い理由は3つ：

| 理由 | 中身 |
|---|---|
| 1社潰れても効かない | 1社に全額入れてその会社が倒産＝**−100%**。500社に分散して1社倒産＝**−0.2%** |
| 手数料が安い | 銘柄を選ぶ手間がないぶん、運営コストが桁違いに低い |
| プロの大半が平均に勝てない | 高い手数料を払ってプロに任せても、長期では平均に負けることのほうが多い |

### 投資信託（とうししんたく）
**みんなからお金を集めて、まとめて運用してくれる箱。**
1万円しかなくても、その箱を買えば中身の何百社にまとめて投資できます。
値段（基準価額）は**1日1回だけ**決まります。

### ETF（上場投資信託）
**投資信託を、株と同じように市場で売り買いできるようにしたもの。**
投資信託が「1日1回の値段」なのに対し、ETFは**リアルタイムで値段が動き、いつでも売買できます**。

### アクティブファンド
**プロが銘柄を選んで「平均に勝とう」とする商品。**
手数料が高く（年1〜2%）、長期では大半がインデックスに負けます。**初心者は選ばなくていい**です。

### 分散投資／集中投資
- **分散**：いろんなものに分けて買う。**卵をひとつのカゴに盛るな**
- **集中**：ひとつに賭ける。当たれば大きいが、外れたら終わり

### 時価総額（じかそうがく）
**その会社まるごとの値段。** 株価 × 発行株数。
小さすぎる会社は値動きが乱暴で、初心者には危険です。

### 配当（はいとう）
**会社の利益のおすそわけ。** 持っているだけで年1〜2回もらえることがあります。

## C. 制度と口座

### NISA（ニーサ）
**利益に税金がかからない特別な口座。**

普通は利益に **20.315%** の税金がかかります（100万円儲けたら約20万円取られる）。
NISAならこれが**ゼロ**。2024年からの新NISAは、つみたて投資枠が年120万円、成長投資枠が年240万円、生涯で1800万円まで、期間は無期限です。

> **勉強も判断もいらないのに、確実に手取りが約20%良くなる唯一の方法。** 使わない理由がありません。

### iDeCo（イデコ）
**老後のための積立制度。** 節税効果はNISAより大きいのですが、**60歳まで1円も引き出せません。**
5年目標の資金には使えないので、老後資金として別に考えてください。

### 特定口座（源泉徴収あり）
**証券会社が税金の計算と支払いを代わりにやってくれる口座。**
初心者はこれを選べば、確定申告の手間がほぼなくなります。

### 単元株（たんげんかぶ）／単元未満株
日本株は原則 **100株がひとまとめ（1単元）** でしか買えません。
株価3,000円の会社なら、最低30万円必要ということです。

**単元未満株サービス**（SBI証券のS株、楽天証券のかぶミニ、マネックスのワン株など）を使えば、**1株から**買えます。資金30万円なら、こちらが現実的です。

## D. 手数料 ― 静かにお金を減らすもの

### 信託報酬（しんたくほうしゅう）
**投資信託を持っている間、毎日かかり続ける手数料。**
「年0.1%」なら、100万円につき年1,000円。

小さく見えますが、長期で効きます。100万円を年7%で運用した場合：

| | 年0.1%の商品 | 年1.5%の商品 | 差 |
|---|---|---|---|
| 10年後 | 195万 | 171万 | 24万 |
| 20年後 | 380万 | 292万 | 88万 |
| **30年後** | **740万** | **498万** | **242万** |

**たった1.4%の差が、30年で242万円。** 商品を選ぶとき、ここは必ず見てください。

### 売買手数料
買うとき・売るときにかかるお金。ネット証券は無料化が進んでいます。

### スプレッド
**買値と売値の差。** 「手数料無料」と書いてあっても、この差の形でコストを払っていることがあります。FXや単元未満株では特に重要です。

## E. 危険な言葉 ★最重要★

### レバレッジ
英語で **「てこ」**。小さい力で重い物を動かす、あの理科の道具です。
投資では **自分のお金より大きな額を動かすこと**。借りたお金で投資するのと同じです。

資金30万円でやると、こうなります。

| 倍率 | 動かす額 | 相場+10% | 相場−10% | 相場−20% |
|---|---|---|---|---|
| **1倍（普通）** | 30万円 | 33.0万（+10%） | 27.0万（−10%） | 24.0万（−20%） |
| 2倍 | 60万円 | 36.0万（+20%） | 24.0万（−20%） | 18.0万（−40%） |
| 3倍 | 90万円 | 39.0万（+30%） | 21.0万（−30%） | 12.0万（−60%） |
| 5倍 | 150万円 | 45.0万（+50%） | 15.0万（−50%） | **全損** |
| 10倍 | 300万円 | 60.0万（+100%） | **全損** | **全損** |
| 25倍（FX最大） | 750万円 | 105.0万（+250%） | **全損** | **全損** |

**利益が◯倍になるということは、損失も◯倍になるということです。**

そして決定的なのがこれ：

| 倍率 | 資金がゼロになる相場の下落 |
|---|---|
| 1倍 | −100%（会社が消滅するレベル） |
| 3倍 | −33% |
| 10倍 | **−10%**（ドル円150円なら15円） |
| **25倍** | **−4%**（ドル円150円なら、わずか6円） |

ドル円が6円動くのは、**数日でふつうに起きます。**

> **レバレッジは腕を増幅する道具です。** 腕がプラスの人は儲けが増え、腕がマイナスの人は破産が早まる。
> 初心者にとっては **破産までの時間を短縮する装置**でしかありません。**最初の2年は絶対に触らないこと。**

### 信用取引（しんようとりひき）
**証券会社からお金や株を借りて売買すること。** 日本株では最大**約3.3倍**まで。
借金なので、**負けたら手持ち以上のお金を失うことがあります。**

### 空売り（からうり）
**持っていない株を借りて先に売り、値下がりしてから買い戻して差額を取る**手法。
下げ相場でも儲けられますが——**上がったときの損に上限がありません。**
株は0円までしか下がりませんが、上には10倍にも100倍にもなり得るからです。初心者は絶対に触らないでください。

### 追証（おいしょう）
**「損が大きすぎるので、追加でお金を入れてください」という証券会社からの請求。**
入れられなければ強制的に決済されます。これで借金が残る人がいます。

### ロスカット／強制決済
**損が一定を超えたとき、証券会社が勝手にポジションを切る仕組み。**
守ってくれる仕組みに見えますが、**発動した時点で資金の大半は消えています。**

### ナンピン
**下がったところで買い増して、平均の買値を下げること。**
うまくいけば早く戻せますが、**下がり続けたら傷が倍になります。** 上級者以外は禁止。

### 塩漬け（しおづけ）
**損を確定したくなくて、値下がりした株を売れずに持ち続けること。**
お金と時間が何年も固定されます。**損切りをしないと、必ずこれになります。**

## F. 注文のしかた

### 現物取引
**自分のお金の範囲だけで売買すること。** 借金なし。**初心者はこれだけ。**

### 成行（なりゆき）注文
**値段を指定せず「いくらでもいいから今すぐ買う／売る」。**
確実に約定しますが、思わぬ値段になることがあります。

### 指値（さしね）注文
**「1,000円以下になったら買う」と値段を指定する注文。**
希望の値段で買えますが、その値段が来なければ買えません。

### 逆指値（ぎゃくさしね）注文 ★重要★
**「1,000円まで下がったら売る」という、損切り専用の注文。**

これを**買った直後に必ず入れてください。**
人間は損が出ると「もう少し待てば戻るかも」と考えてしまいます。逆指値は、**その弱さを機械に肩代わりさせる装置**です。

### 約定（やくじょう）
**売買が成立すること。** 「注文を出した」と「約定した」は別です。

### 板（いた）
**「いくらで何株買いたい人がいるか」の一覧表。**

## G. チャートの言葉

| 言葉 | 意味 |
|---|---|
| **ローソク足** | 一定期間の値動きを1本にまとめた記号。始値・終値・高値・安値の4つが入る |
| **陽線／陰線** | 値上がりで終わった／値下がりで終わった1本 |
| **実体／ヒゲ** | 四角い部分／上下に伸びた細い線 |
| **トレンド** | 値動きの方向。山と谷が両方切り上がれば上昇トレンド |
| **レンジ** | 方向感なく、同じ幅を行ったり来たりしている状態 |
| **支持線（サポート）** | 何度も下げ止まる値段。「床」 |
| **抵抗線（レジスタンス）** | 何度も上げ止まる値段。「天井」 |
| **ブレイク** | 支持線や抵抗線を勢いよく突き抜けること |
| **だまし** | 抜けたと思ったら、すぐ戻ってしまうこと |
| **押し目（おしめ）** | 上昇トレンドの途中で、一時的に下がったところ。買い場の候補 |
| **順張り／逆張り** | 流れに乗る／流れに逆らう。**初心者は順張りだけ** |
| **移動平均線** | 直近◯日間の平均値段を線でつないだもの |
| **ゴールデンクロス** | 短い平均線が長い平均線を下から上に抜く。買いサインとされるが**必ず遅れる** |
| **出来高（できだか）** | その期間に売買された量。**その動きの本気度** |
| **ダイバージェンス** | 値段とインジケーターが逆のことを言っている状態。勢いの衰えのサイン |
| **時間足（じかんあし）** | ローソク1本の長さ。日足なら1本＝1日 |

## H. リスク管理の言葉

### ポジション
**今持っている売買の状態。** 「ポジションを持つ」＝買っている（または売っている）状態にあること。

### 損切り（ロスカット／ストップロス）
**「ここまで下がったら諦めて売る」と決めて、実行すること。**

> **損切りは失敗ではなく、保険料です。** 火災保険を払って火事が起きなかったからといって、損したとは思わないですよね。

### 利確（りかく）
**利益を確定させること＝売って現金に戻すこと。** 売るまで利益は幻です。

### リスクリワード比
**「損する可能性の大きさ」と「狙える利益の大きさ」の比。**
90円の損を覚悟して180円を狙うなら **1:2**。

これが大事な理由：**比率が1:3なら、勝率30%でも資産は増えます。**
10回中7回負けても勝てる。初心者は「当てること」を目指し、経験者は**「負けを小さく、勝ちを大きく」**を目指します。

### 期待値
**1回あたり、平均していくら儲かるか（損するか）。**
「勝率が高い」だけでは意味がありません。**勝率 × 勝ったときの大きさ − 負ける確率 × 負けたときの大きさ**、これがプラスかどうかがすべてです。

### ボラティリティ
**値動きの激しさ。** 高いほど大きく儲かる可能性も、大きく損する可能性も上がります。

### ドローダウン
**資産が、一番高かったところから何%減ったか。**
これが大きいほど、心が折れて途中でやめる確率が上がります。

### ドルコスト平均法
**毎回同じ金額を、決まったタイミングで買い続けるやり方。**

値段が高いときは少なく、安いときは多く買えるので、**買値が自然にならされます。**
「いつ買うか」を考えなくて済むのが最大の利点です。

### リバランス
**崩れた資産の配分を、元の割合に戻す作業。**
「株70：現金30」で始めて株が値上がりし「株80：現金20」になったら、株を少し売って戻す。
**自動的に「高くなったものを売り、安いものを買う」ことになります。** 年1回で十分です。

### 生活防衛資金
**投資とは別に取っておく、生活費の6ヶ月分の現金。**
これがないと、暴落のときに「生活のために底値で売る」羽目になります。**投資の前に、まずこれ。**

## I. 見たら逃げる言葉

| 言葉 | 判定 |
|---|---|
| 「元本保証で高利回り」 | **詐欺。** 元本保証と高利回りは両立しません |
| 「絶対に儲かる」 | **詐欺。** 絶対はありません |
| 「あなただけに特別に」 | **詐欺。** 本当に勝てる方法を他人に配る人はいません |
| 「今だけ」「今すぐ決めて」 | **詐欺。** 考える時間を奪うのが手口です |
| 「未公開株」「AIが自動で稼ぐ」 | **ほぼ詐欺。** |
| 月額◯円のシグナル配信 | 配信者が儲かる仕組み。**勝てる方法は月数千円では売られません** |
