# 2. ローソク足の読み方 ― チャートは「気持ちのグラフ」

---

## 2-1. ローソク足って何？

ローソク足1本は、**ある期間のできごとを1本にまとめた記録**です。

日足（1D）なら、**1本＝1日**。
5分足なら、**1本＝5分**。

### 1本のローソクには、4つの数字が入っている

```
        │  ← 高値（その日、いちばん高かった値段）
      ┌─┴─┐
      │   │  ← この四角い部分を「実体（じったい）」という
      │   │
      └─┬─┘
        │  ← 安値（その日、いちばん安かった値段）
```

| 名前 | 意味 |
|---|---|
| **始値（はじめね）** | その日、最初についた値段 |
| **終値（おわりね）** | その日、最後についた値段 |
| **高値（たかね）** | その日のいちばん高い値段 |
| **安値（やすね）** | その日のいちばん安い値段 |

上下に伸びた細い線を **ヒゲ** と呼びます。

### 陽線（ようせん）と陰線（いんせん）

| | 見た目 | 意味 |
|---|---|---|
| **陽線** | 中が空 or 緑/赤（設定次第） | **終値 > 始値** ＝ その期間で**値上がり**した |
| **陰線** | 中が塗りつぶし or 赤/緑 | **終値 < 始値** ＝ その期間で**値下がり**した |

> ⚠️ 色は国とサイトで逆になります。
> 日本の証券会社：上がり＝**赤**、下がり＝**青**
> 世界標準・TradingViewの初期設定：上がり＝**緑**、下がり＝**赤**
> **どちらが上がりか、必ず自分の画面で確認してから読んでください。**

## 2-2. ローソク足は「買いたい人と売りたい人のケンカの記録」

ここが一番大事な考え方です。

値段が動く理由はたった1つ。
**「買いたい人」と「売りたい人」の力くらべの結果**です。

- 買いたい人が強い → 値段が上がる（陽線）
- 売りたい人が強い → 値段が下がる（陰線）

ローソク1本の形は、その**ケンカの経過**を教えてくれます。

### 形からわかること

**① 実体が長い陽線（大陽線）**
```
    │
  ┌─┴─┐
  │   │   買いたい人が圧勝した日。
  │   │   勢いが強い。
  │   │
  └─┬─┘
    │
```

**② 下ヒゲが長い（かなづち／ハンマー）**
```
  ┌─┐
  │ │     一度ぐっと下げられたけど、
  └┬┘     買いたい人が押し返して戻した。
   │      「安いところで買いたい人がいる」サイン。
   │
   │
```

**③ 上ヒゲが長い（流れ星）**
```
   │
   │      一度ぐっと上げたけど、
   │      売りたい人に押し戻された。
  ┌┴┐     「高いところで売りたい人がいる」サイン。
  └─┘
```

**④ 実体がほとんどない（十字線／同時線）**
```
    │
  ──┼──   買いも売りも互角。迷っている。
    │      トレンドの折り返し地点で出やすい。
```

> 💡 **暗記しないでください。**
> 「長い下ヒゲ＝下で買われた」「長い上ヒゲ＝上で売られた」
> この2つの**理屈**さえわかれば、あとは全部その応用です。
> 「〇〇の法則」のような形の名前を100個覚えても、勝てるようにはなりません。

## 2-3. トレンド ― チャートで一番大事なこと

値段の動きには、3種類しかありません。

| 状態 | 見た目 | 覚え方 |
|---|---|---|
| **上昇トレンド** | 右肩上がり | 山も谷も、だんだん高くなる |
| **下降トレンド** | 右肩下がり | 山も谷も、だんだん低くなる |
| **レンジ（横ばい）** | 横に行ったり来たり | 同じ幅を往復している |

### 判定のしかた（超シンプル）

チャートの「山（高値）」と「谷（安値）」を見ます。

- **山が前より高い ＆ 谷も前より高い** → **上昇トレンド**
- **山が前より低い ＆ 谷も前より低い** → **下降トレンド**
- そのどちらでもない → **レンジ**

```
上昇トレンド                    下降トレンド
        ／＼                    ＼
      ／    ＼／＼                 ＼／＼
    ／            ＼／                   ＼／＼
  ／                                          ＼
 谷↑ 谷↑ 谷↑ ← 谷が切り上がる     谷↓ 谷↓ ← 谷が切り下がる
```

### なぜトレンドが大事か

**トレンドに逆らうのは、川の流れに逆らって泳ぐのと同じ**だからです。
できなくはないけど、めちゃくちゃ疲れるし、たいてい流されます。

初心者のうちは、**上昇トレンドのものを、押し目（一時的に下がったところ）で買う**。
これだけを狙ってください。下降トレンドのものには手を出さない。

> 「安くなったから買う」は、初心者が最も損する考え方です。
> 下降トレンド中の株は「安い」のではなく「**もっと安くなる途中**」であることが多い。

## 2-4. 支持線と抵抗線 ― チャートに引く2本の線

### 支持線（サポート）＝ 下で支える床
値段が何回も下げ止まっている値段のライン。
「ここまで下がったら買いたい人が出てくる」場所。

### 抵抗線（レジスタンス）＝ 上でぶつかる天井
値段が何回も上げ止まっている値段のライン。
「ここまで上がったら売りたい人が出てくる」場所。

```
        天井（抵抗線）
 ─────────────────────────
     ／＼    ／＼    ／＼
   ／    ＼／    ＼／    ＼
 ─────────────────────────
        床（支持線）
```

### なぜ効くのか（これが理解できると強い）

たとえば「1000円」で何回も跳ね返っているとします。
すると、多くの人の頭の中にこう記憶されます。

- 「1000円で買ったら儲かった」→ また1000円で買おう
- 「1000円で売り損ねた」→ 次に1000円が来たら売ろう
- 「1000円は底だ」と皆が思う → 実際に1000円で買いが集まる → 本当に止まる

つまり **「みんながそう思っているから、そうなる」**。
チャートは値段のグラフであると同時に、**参加者の記憶と気持ちの地図**なんです。

### 引き方（TradingViewでの操作）

1. `Alt + H` で水平線ツール
2. 何回も止まっている値段のところをクリック
3. **ピッタリ合わせようとしない**。ヒゲの先と実体で少しズレるのが普通なので、
   細い線ではなく **長方形ツールで「ゾーン（帯）」として塗る** ほうが実戦的

💡 **線は3〜4本まで。** 線だらけのチャートは、どんな動きも「線に当たった」ことになり、意味を失います。

### ブレイク（突破）と、だまし

線を勢いよく抜けることを **ブレイク** といいます。
天井を抜けた → 上に行きやすい。床を割った → 下に行きやすい。

そして **抜けたあと、天井と床は役割が入れ替わります**。
（抜けた天井は、次は床になる。これを「ロールリバーサル」といいます）

ただし、**抜けたと思ったらすぐ戻る「だまし」**も非常に多いです。
だから「抜けた瞬間に飛びつく」のではなく、
**抜けたあと、一度戻ってきて、そこで支えられたのを確認してから**入るほうが安全です。

## 2-5. 出来高（できだか）― 動きの「本気度」

チャートの下にある棒グラフです。
「その期間に、どれだけの量が売買されたか」を表します。

**出来高＝その動きの本気度・信頼度**と考えてください。

| 状況 | 意味 |
|---|---|
| 値上がり ＋ **出来高が多い** | **本物の上昇**の可能性が高い（大勢が参加している） |
| 値上がり ＋ 出来高が少ない | 力が弱い。続かないかも |
| 線をブレイク ＋ **出来高が急増** | 本物のブレイクの可能性が高い |
| 線をブレイク ＋ 出来高が普通 | **だまし**の可能性が高い |

> たとえるなら、
> **値段＝どっちに動いたか。出来高＝どれくらいの人数が押したか。**
> 1人で押したドアと、100人で押したドアでは、意味がぜんぜん違います。

## 2-6. 時間足の使い分け ― 「木を見て森も見る」

同じ銘柄でも、時間足を変えると景色が変わります。

| 時間足 | 1本の長さ | 見えるもの |
|---|---|---|
| **月足（1M）** | 1ヶ月 | 何年もの大きな流れ |
| **週足（1W）** | 1週間 | 数ヶ月〜1年の流れ |
| **日足（1D）** | 1日 | **数週間〜数ヶ月の流れ（初心者はここ）** |
| 4時間足 | 4時間 | 数日の流れ |
| 1時間足〜5分足 | 1時間〜5分 | 1日の中の細かい動き（上級者向け） |

### プロがやっている順番（マルチタイムフレーム分析）

1. **週足で「森」を見る** → 大きな流れは上か下か
2. **日足で「木」を見る** → 具体的にどこで買うか
3. （必要なら）**1時間足で「枝」を見る** → 入るタイミングを細かく

**大原則：長い時間足の流れに、短い時間足で逆らわない。**
週足が下向きなのに、5分足が上がっているから買う——これが一番やられるパターンです。

## 練習課題（この章）

1. `TSE:7203`（トヨタ）を日足で開き、**上昇トレンド／下降トレンド／レンジ**がどこか、指でなぞってみる
2. 水平線（`Alt+H`）を使って、**何度も止まっている値段に線を3本**引く
3. その線のところで、ローソクがどんな形になっているか観察する（長い下ヒゲが出ていないか？）
4. ブレイクした場面を探し、そのときの**出来高が増えていたか**を確認する
5. 同じ銘柄を**週足**で見て、日足で見えていた動きが「大きな流れの中のどこ」なのか確認する

これを **10銘柄ぶん** やってください。それだけで、他の初心者よりずっと目が良くなります。
