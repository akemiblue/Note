# 3. インジケーター ― 補助の道具の使い方

---

## 3-0. 最初に、いちばん大事な注意

インジケーターは **「値段を計算し直したもの」** です。
新しい情報が出てくるわけではありません。

> **値段が「本体」で、インジケーターは「影」です。**
> 影をどれだけ増やしても、本体より先には動きません。

だから：

- ❌ 「もっと良いインジケーターを探せば勝てる」→ **一生見つかりません**
- ❌ 5個も6個も重ねる → 意見が食い違って動けなくなる（分析まひ）
- ⭕ **2〜3個まで。** 役割が違うものを組み合わせる

**この章で覚えるのは、たった3つでいいです。**
移動平均線 ／ RSI ／ 出来高。あとはオマケです。

### TradingViewでの追加方法
上のバーの「**⚡ インジケーター**」→ 検索して選ぶ → チャートに乗る。
消したいときは、チャート左上に出るインジケーター名にマウスを乗せて「×」。

## 3-1. 移動平均線（MA）― いちばん大事な1本

### 何をしているのか

「**直近◯日間の値段の平均**」を、毎日計算して線でつないだものです。

たとえば5日移動平均線なら、
今日の点＝（今日＋昨日＋一昨日＋3日前＋4日前）の終値 ÷ 5

テストの成績でたとえると：
1回のテストは上下しますが、**「直近5回の平均点」**を見れば、
自分が伸びているのか落ちているのかがハッキリわかりますよね。あれと同じです。

### 何がわかるのか

| 見るポイント | 意味 |
|---|---|
| 線が**上を向いている** | 上昇トレンド |
| 線が**下を向いている** | 下降トレンド |
| 線が**横ばい** | レンジ（方向感なし） |
| 値段が線の**上**にある | 買った人が平均的に勝っている＝強い |
| 値段が線の**下**にある | 買った人が平均的に負けている＝弱い |

### SMAとEMAの違い

- **SMA（単純移動平均）**：全部の日を平等に平均。素直でなめらか
- **EMA（指数移動平均）**：**最近の日を重く**扱う。値段の変化に早く反応する

初心者は **SMAでOK**。細かい違いに悩むほどの差はありません。

### 何日の線を使う？

定番はこれ。世界中の人が見ているので、**見ている人が多い＝効きやすい**。

| 期間 | 用途 |
|---|---|
| **25日** or 20日 | 短期の流れ（日本では25日が定番） |
| **75日** | 中期の流れ |
| **200日** | **長期の流れ。最重要。** 世界中のプロが見ている |

**おすすめ設定：25日 と 200日 の2本だけ。**

### 使い方（実戦）

**① トレンドの判定（これがメイン）**
- 値段が200日線の**上** → 買っていい相場
- 値段が200日線の**下** → **手を出さない**（ここを守るだけで大損の大半は防げます）

**② 押し目（買い場）の目安**
上昇トレンド中に、値段が25日線まで下がってきて、**跳ね返ったところ**。
線が「見えないクッション」のように働きます。

**③ ゴールデンクロス／デッドクロス**
- **ゴールデンクロス**：短い線が長い線を**下から上に**抜く → 買いサイン
- **デッドクロス**：短い線が長い線を**上から下に**抜く → 売りサイン

> ⚠️ ただし **クロスは必ず遅れます**。平均なので当然です。
> レンジ相場だとクロスしまくって、その全部が損になります（これを「ダマシ」といいます）。
> **クロスだけで売買しないこと。** トレンドの確認材料の1つとして使ってください。

## 3-2. RSI ― 「上がりすぎ・下がりすぎ」を測る

### 何をしているのか

直近（ふつう14本）の中で、**値上がりの勢いと値下がりの勢いの比率**を
0〜100の数字にしたものです。

- **70より上** → 買われすぎ（上がりすぎ）
- **30より下** → 売られすぎ（下がりすぎ）
- 50前後 → 普通

たとえるなら **「ダッシュの息切れメーター」**。
ずっと全力疾走したら、そろそろ息が切れるよね、というのを数字にしたものです。

### 使い方

**① 逆張りの目安（レンジ相場で有効）**
横ばいの相場で、RSIが30以下 → そろそろ反発するかも。

> ⚠️ **強いトレンド中は絶対に逆張りしないでください。**
> 強い上昇相場では、RSIが70を超えたまま何週間も上がり続けます。
> 「70超えたから売り」で入ると、上がり続ける株にひたすら負けます。
> **RSIの逆張りは「レンジのときだけ」の道具です。**

**② ダイバージェンス（これは強力）**

値段とRSIが**逆のことを言っている**状態。

- **弱気ダイバージェンス**：値段は**高値を更新**したのに、RSIは**前より低い**
  → 上がってるけど**勢いは落ちている**＝そろそろ天井かも
- **強気ダイバージェンス**：値段は**安値を更新**したのに、RSIは**前より高い**
  → 下がってるけど**売りの力は弱まっている**＝そろそろ底かも

```
値段：    ／＼      ／￣＼ ← 高値を更新（もっと高い）
                  
RSI ：    ／＼      ／＼   ← でも山は前より低い＝勢いが落ちている
                             = 弱気ダイバージェンス
```

これは「**車はまだ前に進んでいるけど、アクセルは緩んでいる**」状態。
止まるか、バックするかの前ぶれです。

## 3-3. MACD ― トレンドの変わり目を見る

MACD（マックディー）は、**2本の移動平均線の差**をグラフにしたものです。

構成：
- **MACD線**（速い線）
- **シグナル線**（遅い線）
- **ヒストグラム**（2本の差を棒グラフにしたもの）

### 使い方

| サイン | 意味 |
|---|---|
| MACD線がシグナル線を**上抜け** | 買いの勢いが出てきた |
| MACD線がシグナル線を**下抜け** | 売りの勢いが出てきた |
| ヒストグラムの棒が**伸びている** | 勢いが加速中 |
| ヒストグラムの棒が**縮み始めた** | **勢いが衰えてきた（これが実は一番役立つ）** |
| ゼロラインより**上** | 全体として上向き |

RSIと同じく**ダイバージェンス**も使えます。

> 💡 移動平均線を使っているので、MACDも**遅れます**。
> 「先読みの道具」ではなく「**今の勢いを確認する道具**」だと思ってください。

## 3-4. ボリンジャーバンド ― 値段の「いつもの範囲」

移動平均線の上下に、**「だいたいこの範囲に収まるよ」という帯**を描いたものです。

- 真ん中の線＝移動平均線
- 上下の線＝そこから統計的に離れた位置（±2σ＝シグマ）

理論上、値段の約95%は ±2σ の中に収まります。

### 見るポイント

| 状態 | 意味 |
|---|---|
| **帯が狭い（スクイーズ）** | 値動きが静か。**大きな動きの前ぶれ**のことが多い |
| **帯が急に広がる（エクスパンション）** | 大きな動きが始まった |
| 値段が上のバンドに**貼り付いて上昇** | **強い上昇トレンド**（売りではない！） |

> ⚠️ よくある間違い：「上のバンドに触ったから売り」
> **強いトレンドでは、バンドに沿って延々と上がり続けます（バンドウォーク）。**
> ボリンジャーバンドは「反転の道具」ではなく、
> **「静かか、荒れているか」を見る道具**として使うのが正解です。

## 3-5. 出来高系 ― 本気度を測る

第2章で説明した出来高。プラスして知っておくといいもの：

- **出来高移動平均**：出来高にも平均線を引くと「いつもより多いか」がひと目でわかる
- **VWAP（出来高加重平均価格）**：その日、**平均していくらで売買されたか**の線。
  デイトレの人が「今、自分は平均より上か下か」を判断するのに使います

## 3-6. 一目均衡表（いちもくきんこうひょう）― 日本生まれ

雲（抵抗帯）で有名な、日本人が作った指標です。

**初心者は「雲」だけ見ればOK。**

- 値段が**雲の上** → 強い
- 値段が**雲の下** → 弱い
- 値段が**雲の中** → 方向感なし。**手を出さない**

雲が厚いほど、突き抜けにくい壁になります。

## 3-7. 【重要】初心者におすすめの組み合わせ

**これだけでいいです：**

```
① 移動平均線 25日 + 200日   … 流れ（トレンド）を見る
② 出来高                     … 本気度を見る
③ RSI(14)                    … 行き過ぎを見る
```

**役割が3つとも違う**のがポイントです。
似た役割のインジケーターを何個も並べても、同じことを3回言われるだけで、
「たくさんのサインが一致した！」と勘違いする原因になります。

### 判断の順番（テンプレート）

1. **週足の200日線** → 上向きか？ 下向きなら見送り
2. **日足で値段は200日線の上か？** → 下なら見送り
3. **25日線まで押してきたか？** → 買い場の候補
4. **そこで下ヒゲが出ているか？ 出来高は？** → 買いの手が入っているか確認
5. **RSIが30〜50あたりまで下がって回復しているか？** → 息を整えた証拠
6. → **全部○なら検討。1つでも×なら見送り。**

**見送りは、負けではありません。**
バッターが悪い球を見送るのは、正しいプレーです。

## 練習課題（この章）

1. チャートに **SMA25 と SMA200** を追加して、色を変える
2. 過去1年で、**値段が200日線の上にいた期間**と**下にいた期間**を分け、
   それぞれ「その後どうなったか」を見る
3. **RSIを追加**し、ダイバージェンスが起きている場所を3つ探す
4. インジケーターを**5個以上乗せてみて**、いかに判断しづらくなるかを体感する（← これ大事）
5. そのあと**3個に戻す**
