# 9. 毎日のルーティン ― 相場を読む目を養う

**目的：判断するためではなく、目を養うため。**
生活防衛資金ができるまでの期間は、**見るだけ。売買ボタンは押さない。**

このルーティンは、[講座B（相場の教養）](08-kouza-review.md)と直結しています。
毎日見る7項目は、講座Bの「相場の4局面」を判定するための**計器盤**です。

---

## 時間割

### 🌅 朝（15分）

| 時間 | やること |
|---|---|
| 3分 | **「世界の株価」で7項目をチェック** |
| 2分 | **経済指標カレンダーで今日の★★★を確認**（マネックス証券） |
| 10分 | **ブルームバーグ ＋ 日経新聞の見出しを流す**（本文は気になったものだけ） |

### 🌙 夜（30分＋WBS）

| 時間 | やること |
|---|---|
| 5分 | **TradingViewで7項目を日足で見る** |
| **2分** | **📝 1行メモを書く** ← **これが本体** |
| 約1時間 | **WBS（ワールドビジネスサテライト）**／録画・倍速OK |

> ⚠️ 忙しい日は **「朝3分（7項目）＋夜2分（1行メモ）」の5分版**でよい。
> **途切れないことが最重要。**

## 見る7項目と、その意味

| 項目 | 何のバロメーターか |
|---|---|
| **日経平均株価** | 日本株全体の体温 |
| **NYダウ** | 米国株＝世界の中心。日本株は翌朝これに引っ張られる |
| **米10年国債（利回り）** | **すべての基準。**上がると株に逆風、下がると追い風 |
| **ドル円** | 円安→日本株にプラス。**自分の米国資産は円換算で増える** |
| **ドルインデックス** | ドルの総合的な強さ（主要通貨に対して） |
| **ゴールド** | 不安とインフレのバロメーター |
| **原油** | **インフレの原料。**講座Bの「あらゆるモノの原料」 |

|---|---|---|---|
| 金融相場 | 下がる | 上がり始め | 米10年金利↓ ＋ 株↑ |

## チェックする経済指標（米国・重要度★★★）

| 指標 | タイミング | 見どころ |
|---|---|---|
| **FOMC（政策金利）** | 年8回 | **最重要。**利上げ／利下げ／据え置き |
| **雇用統計** | 毎月・第1金曜（米国時間） | **月に一度の最大イベント** |
| **ADP雇用統計** | 雇用統計の2営業日前 | 雇用統計の前哨戦 |
| **ISM製造業景況指数** | 毎月・第1営業日 | **50が分岐点。**50超＝拡大、50割れ＝縮小 |
| **ISM非製造業景況指数** | 毎月・第3営業日 | 米国経済の大半は非製造業 |
| **GDP** | 四半期ごと | 経済全体の成績表 |
| **小売売上高** | 毎月 | 消費者が実際に使っているか |

※発表日・時刻は変わります。マネックス証券などの経済指標カレンダーで毎朝確認すること。

## 📝 毎日の1行メモ（これが本体）

見るだけでは記憶に残りません。
講座Aの「学習効率ピラミッド」のとおり（読む10% ／ 他人に教える90%）、
**アウトプットしないと身につきません。**

毎日、この1問だけ答える。

```
【   月   日】

今日いちばん動いたのは？  ______________________

なぜ動いた？（推測でOK）  ______________________
                          ______________________
```

**推測で構いません。当たり外れは重要ではありません。**
「値動きと理由を結びつけようとする」行為そのものが、相場観をつくります。

3ヶ月続けると、ニュースを見た瞬間に
**「これは金利が動くな」**と思えるようになります。

## ★このルーティンのルール★

1. **売買ボタンを押さない。** 見るだけ
2. **TradingViewでは7項目だけ見る。** 銘柄探しをしない（必ず買いたくなるため）
3. **忙しい日は5分版でいい。** ゼロの日を作らない
4. **1行メモは毎日書く。** 見た記録より、考えた記録が資産になる
5. **SNS・掲示板・「この銘柄が来る」動画は、このルーティンに入れない**

> 毎日相場を見ると、必ず「何かしたくなる」。それがポジポジ病の入口です。
> 生活防衛資金ができるまでは、**情報収集の目的は「判断」ではなく「学習」**です。
> 盾ができたら、同じルーティンが「判断のための道具」に変わります。
